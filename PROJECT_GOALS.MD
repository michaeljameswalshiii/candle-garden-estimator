# Candle Garden Estimator - Project Goals

## Vision
A consumer mobile app (iOS + Android) that lets customers photograph their used candles at home, get an instant refill quote, purchase the refill service, buy goods, and book classes — all seamlessly.

## Core Objectives (MVP)
1. **Reliable Refill Estimator** ← Current #1 Priority
   - High-accuracy volume estimation from user photos
   - Move beyond inconsistent Bedrock Nova Lite results
   - Excellent user experience even when photos are imperfect

2. **Seamless Purchase Flow**
   - Quote → Square checkout (refills + goods)

3. **Class Booking**
   - Basic integration with Squarespace

## Success Metrics
- Refill estimator success rate >80% on first try for typical user photos
- Users can complete a full refill purchase end-to-end
- App approved on Apple App Store and Google Play

## Current Priorities
1. Improve refill estimator (Grok vision exploration, prompt engineering, fallbacks)
2. Complete purchase flow with Square
3. Finish Squarespace class sync
4. Polish & submit to app stores

## Tech Stack
- React Native + Expo (mobile)
- AWS CDK + Lambda + Bedrock (current)
- Square for payments
- Squarespace for classes
